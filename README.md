# voice-recorder

龍哥的錄音頁：https://luckydragon0920.github.io/voice-recorder/

- 一鍵錄音（電腦快速鍵 R 開始／暫停、S 結束），瀏覽器內建聽寫即時出字，每段標時間。
- 聽寫中斷會自動接上；逐字稿與錄音片段即時暫存在瀏覽器，分頁意外關掉可以接著錄。
- 電腦版多一個「錄電腦播放的聲音」：錄 Chrome 分頁的聲音（線上課程），不即時出字，錄完交給 Mac Whisper 精修。
- 即時逐字稿用停頓規則加標點（停約 0.7 秒加「，」、段尾加「。」、問句加「？」），不是 AI，會有誤差；原文存在 raw。
- 錄完：「複製並開啟整理頁」一鍵複製逐字稿並開 claude.ai 整理頁。
- 錄完：複製逐字稿、下載逐字稿 .txt、下載錄音檔。
- 錄音與逐字稿只存在使用者自己的裝置，不會上傳。整理（大綱、結論、會議紀錄、課程講義）在 claude.ai 的私人整理頁進行。

版本：1.2.0
